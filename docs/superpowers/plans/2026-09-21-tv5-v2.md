# TV5 Backend V2 Implementation Plan

> For agentic workers: use superpowers:executing-plans. Người dùng yêu cầu triển khai trực tiếp.

**Goal:** hoàn thiện phần backend sở hữu theo Issue #50, báo riêng dependency AI chưa có.
**Architecture:** V1 giữ nguyên; V2 API/worker cùng SQLAlchemy database và storage abstraction; outbox, CAS, immutable runs, separate corrections.
**Tech Stack:** FastAPI, SQLAlchemy, Alembic, PostgreSQL, Celery/Redis, Pillow, pypdf, openpyxl.
**Spec:** docs/superpowers/specs/2026-09-21-tv5-v2.md

## Global Constraints
- 13 canonical header fields; 5 lifecycle states.
- Không OCR/KIE extraction logic trong backend; không overwrite machine output.
- Queue payload chỉ receipt_id; API v1 không đổi.
- Comments/PR/docs triển khai bằng tiếng Việt; không đóng issue trước nghiệm thu.

## Review Focus
- Enqueue thất bại sau commit: outbox còn pending, dispatch được lại.
- Worker cũ hoàn thành sau lease: fencing ngăn thay đổi state/history.
- Hai browser sửa/verify cùng version: một request nhận 409.
- Formula-like strings và số 0 đầu: export không tạo công thức/mất identifier.
- Malformed PDF/schema/provenance: typed failure, không NEEDS_REVIEW giả.

### Task 1: Database và contract
Files: backend/app/v2/{models,contracts,errors}.py, backend/migrations/, backend/tests/v2/.
Produces: Base, Invoice, Attempt, MachineRun, Cell, Outbox, Audit; validate_result(result,evidence,ids).
- [ ] Viết test schema/status/provenance và migration không làm mất bảng legacy.
- [ ] Chạy pytest backend/tests/v2: phải FAIL vì V2 chưa tồn tại.
- [ ] Tạo models, validators, Alembic migration additive.
- [ ] Test SQLite và PostgreSQL khi có service.

### Task 2: Upload/API/persistence
Files: backend/app/v2/{uploads,service,api}.py, backend/app/main.py.
Consumes: Task 1 models. Produces: InvoiceService.upload/detail/list/source/retry.
- [ ] Test upload PNG/JPEG/PDF, MIME mismatch, empty/corrupt/oversized, traversal filename.
- [ ] Test API v2 tồn tại, v1 regression vẫn pass.
- [ ] Implement source storage và transactional outbox.

### Task 3: Processing
Files: backend/app/v2/{processing,providers,runtime,worker}.py.
Consumes: InvoiceService và models; produces: Processor.process(receipt_id), recover_expired(), dispatch_pending().
- [ ] Test duplicate/race/retry/new IDs/schema failures và stale fencing.
- [ ] Implement atomic claim, immutable OCR/KIE persistence, projected cells, recovery.
- [ ] Wire Celery task và periodic outbox/reaper; retry persistence errors có giới hạn.

### Task 4: Review/export
Files: backend/app/v2/{review,exports}.py và api.py.
Consumes: Cell machine data và Invoice version. Produces: correction/review/verify/history/export.
- [ ] Test old version 409, machine unchanged, unresolved review blocked, all formats.
- [ ] Implement review CAS và audited corrections; verified-only exports.
- [ ] Kiểm tra leading zeros, tiếng Việt, line/tax rows và formula injection.

### Task 5: Runtime, verification và bàn giao
Files: openapi/openapi-v2.yaml, infra/*v2*, .github/workflows/backend-v2.yml, docs/backend-v2.md.
- [ ] Đồng bộ OpenAPI với runtime bằng generator và equality test.
- [ ] Chạy backend + contract suites, migration roundtrip và PostgreSQL khi khả dụng.
- [ ] Tạo smoke dùng provider thật, không fake mặc định; ghi dependency blockers.
- [ ] Review độc lập, sửa lỗi quan trọng, push Draft PR tiếng Việt, ZIP source có README.

## Ledger
Pre-flight: tasks 2–4 dùng chung models/session; worker/API không tạo persistence thứ hai.
Ruling: giữ legacy v1, không tự map dữ liệu cũ; main chưa có migrations nên migration V2 tạo bảng có prefix và không đụng bảng cũ.
