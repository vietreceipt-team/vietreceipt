# Example payloads

These files demonstrate the v1.3 contract shape, data types and cross-module linkage only.

Confidence values, processing durations, engine/extractor names and versions, UUIDs, run IDs and OCR block IDs are illustrative values. They are not benchmark results, production defaults, performance claims or evaluation evidence.

`annotation-record.example.json` demonstrates the separate ground-truth annotation schema v1.0 under KIE guideline v1.1. It is synthetic, links only to blocks in `ocr-result.json`, and must not be treated as a dataset record, machine output or benchmark result.
