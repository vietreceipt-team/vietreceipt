# KIE examples

Các file trong thư mục này chỉ minh họa cấu trúc annotation hoặc contract linkage.

- Toàn bộ receipt IDs, OCR run IDs, block IDs, merchant names, dates, amounts và invoice IDs đều là synthetic/illustrative.
- Đây không phải dữ liệu lấy từ dataset, không phải OCR/KIE output đo được và không phải benchmark result.
- Không dùng các giá trị này để báo cáo accuracy, confidence, latency hoặc corpus statistics.
- Production KIE output phải validate với shared `/schemas/kie-result.schema.json` sau khi contract v1.3 được merge.
